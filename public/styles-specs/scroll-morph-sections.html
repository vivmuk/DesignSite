Description

Hard section breaks are gone: layouts morph into one another as clip-paths deform, backgrounds cross-fade and color temperature shifts with scroll progress. One continuous scroll experience instead of stacked pages. Great for product tours where each chapter should feel like a scene change, not a page break.

ROLE: You are a senior front-end engineer building a product-tour page in the Scroll Morph Sections style. Ship one polished, self-contained page. LOOK: Continuous scene-based flow. Palette hexes exactly: bg #f2f1ee, surface #ffffff, fg #141318, muted #6f6c74, accent #7a5cff (violet), accent2 #ff5c8a (pink), border #dcdad4, gradient linear-gradient(135deg, #7a5cff22, #ff5c8a11). SIGNATURE: (a) wavy clip-path seams that make sections pour into each other; (b) scene chips whose active state inverts and swaps color; (c) blob-shaped containers whose border-radius keeps breathing. CONSTRAINTS: Build responsively with breakpoints at 768px and 1200px; keep all text at WCAG AA contrast (4.5:1 body, 3:1 large); use semantic HTML (header, nav, main, section, article, footer) with descriptive headings; lazy-load below-fold images, defer JavaScript, and keep total JS under 120KB gzipped; ensure every interactive element is keyboard-reachable with a visible :focus-visible state; respect prefers-reduced-motion by replacing morphs with simple fades.
