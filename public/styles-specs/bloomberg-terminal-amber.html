Description

The trading floor distilled: amber monospace columns on pure black, function-key chrome along the bottom, and every row a live quote. No rounded corners, no gradients, no mercy. Information density is the aesthetic — built for terminals, tickers, and people who price risk for a living.

Agent build prompt — copy this into any AI agent

ROLE: You are a terminal-emulator UI engineer. Build a single-page market terminal in the Bloomberg Terminal Amber style. LOOK: Black bg #050505, panel #0E0D0A, amber text #FFB000, dim amber #9C6B00, bright amber #FFD54A, green up #00C853, red down #FF5252, border #3A2E10, no gradients. Import: <link href="https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500;700&display=swap" rel="stylesheet">. IBM Plex Mono exclusively, 13px base, uppercase headers. LAYOUT: 1) Top status line: ALL-CAPS amber, UTC clock right. 2) Main grid of panels: quotes table (8 columns), candlestick chart panel, order book, news headlines. 3) Command line with blinking block caret. 4) Crawling ticker above the function-key bar. 5) Function-key chrome: F1 HELP F2 GOVMT F3 EQUITY F8 NEWS F9 EXECUTE. MOTION: Quote cells flash bg amber 400ms on change (add/remove class). Green/red flash for direction. Ticker crawls 60px/s via rAF, pauses on hover. Caret blinks 530ms step-end. Row insert expands 150ms. No easing libraries — keep it raw. SIGNATURE: (a) box-drawing-character panel borders, (b) function-key chrome bar, (c) blinking block caret command line. CONSTRAINTS: Semantic <table> for quotes with proper <th scope>, tabular-nums everywhere, AA contrast is inherent (amber on black = 9:1), keyboard-first: number keys jump panels, `/` focuses command line; throttle DOM updates at 250ms; no layout shift (fixed row heights); reduced-motion stops ticker.
