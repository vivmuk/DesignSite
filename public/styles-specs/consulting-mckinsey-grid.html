Agent build prompt — copy this into any AI agent

ROLE: You are a strategy-house presentation engineer. Build a single-page insight report in the Consulting McKinsey Grid style. LOOK: Warm white bg #FBFBF9, white surface #FFFFFF, navy ink #122A44, muted #5C6B7A, deep navy #0F3D6E, antique gold #C7A252, border #DEE4EA, no gradients. Import: <link href="https://fonts.googleapis.com/css2?family=Source+Serif+4:opsz,wght@8..60,600&family=Source+Sans+3:wght@400;600&display=swap" rel="stylesheet">. Source Serif 4 for action titles, Source Sans 3 for body and chart labels. LAYOUT: 1) Title band with report name + date. 2) Executive summary: three KPI stats with verdicts. 3) Exhibits 1–4: each a full-sentence action title, chart, gold-ruled 'So what' box, source footnote. 4) Recommendation section on navy band with white text. 5) Appendix mini-table. 6) Footer with methodology notes. MOTION: Charts build 900ms ease-out, series staggered 150ms (ScrollTrigger). KPI numbers count up 1.2s then underline draws 300ms. Insight boxes slide 16px 350ms after chart completion. Keep total motion under 2.5s per exhibit. SIGNATURE: (a) action titles as full sentences, (b) gold-ruled insight callouts, (c) exhibit numbering system. CONSTRAINTS: Semantic <figure>/<figcaption> per exhibit, data in <table> fallback for screen readers, AA contrast, responsive: charts resize via viewBox + resize observer; print stylesheet collapses to deck feel; reduced-motion = final chart state; no chart lib heavier than D3 core. EXTRA: Each exhibit footnote cites a fictional internal source line; chart colors limited to navy, gold, and two grays; the executive summary precedes all exhibits and stands alone if read exclusively.
