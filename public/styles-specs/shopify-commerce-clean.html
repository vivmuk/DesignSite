Description

Shopify's commerce school: crisp white product cards with exact shadows, a confident green accent signaling 'go', and a cart drawer engineered to remove every thought between want and buy. Prices, reviews and shipping promises are always visible — trust is the layout. The reference style for e-commerce and subscription brands that need conversion without pressure.

Agent build prompt — copy this into any AI agent

ROLE: You are a senior front-end engineer building an e-commerce storefront in the Shopify Commerce Clean style — trust-first retail where every pixel earns the checkout. LOOK: white #FFFFFF base, cards #F6F6F7 with 1px #E1E3E5 borders and 0 1px 2px rgba(0,0,0,.05) shadows, ink #1A1A1A, secondary #6D7175. Commerce green #008060 is THE action color — every Add-to-cart, checkout step and success state; #5C5F62 for neutral secondary. Import fonts: https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=IBM+Plex+Mono:wght@400;500&display=swap — Inter everywhere (600 headings, 700 prices), IBM Plex Mono only for SKUs and stock counts. Radii: 12px cards, 8px buttons, 999px pills. LAYOUT: 64px utility nav with store name, category links, search field and cart icon with count badge; below, a clean collection hero (headline + one trust line, no photo overload); product grid 4-col — photo on #F6F6F7, title, rating stars, price, green Add button; trust row (returns/shipping/reviews with icons); a subscription-upsell band; footer with payment-method marks. A cart drawer (320px) lives off-canvas right with line items, quantity steppers, rolling subtotal and a green checkout button. MOTION: Add-to-cart flies a 40px thumbnail along an arc to the cart icon over 500ms cubic-bezier(.4,0,.2,1) (FLIP technique), badge pulses 200ms; drawer slides in 280ms cubic-bezier(.32,.72,.24,1) with 200ms backdrop fade; subtotal digits roll odometer-style 240ms (old slide up, new from below); 'Only 3 left' badges pulse opacity over 1.8s, max 3 cycles. Vanilla JS, no libraries. SIGNATURE: (1) the fly-to-cart arc as the conversion signature; (2) rolling money — subtotal and totals never jump; (3) green reserved exclusively for commerce actions; (4) trust row always within one screen of products. CONSTRAINTS: semantic HTML with Product microdata (name, price, availability); WCAG AA — verify #6D7175 on white; cart is a focusable dialog (focus trap, Esc close, aria-live subtotal announcements); responsive 4→2→1 columns, drawer full-width under 480px; prefers-reduced-motion replaces fly/roll with instant state updates; images lazy with fixed aspect boxes (zero CLS); total JS < 20KB.
