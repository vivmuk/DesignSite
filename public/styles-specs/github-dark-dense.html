Description

The developer's home turf: charcoal panels, tabular everything, syntax-colored code embedded mid-page and dense metadata rows. It is comfortable at very high information density and never wastes a pixel. For code products, docs and engineering dashboards.

Agent build prompt — copy this into any AI agent

ROLE: You are a senior front-end engineer building a code-platform landing page in the GitHub Dark Dense style — maximum information, zero fluff, developer-native comfort. LOOK: charcoal #0D1117 background, #161B22 panels, #30363D hairline borders; text #E6EDF3, muted #7D8590, blue #2F81F7, code-green #7EE787, diff-red #F85149. Import: https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&family=Fira+Code:wght@400;500&display=swap. Counters use tabular-nums. Density is high: 12–14px body, 8–12px paddings, tight line heights — but hierarchy stays crisp via weight and muted color, never blur or shadow. LAYOUT: top nav with search box, org switcher and counter badges; hero as two columns: headline + install command left, a live-looking file browser with tabs right; a diff/PR section showing green and red gutters; stats band (stars, forks, issues) counting up; feature table with row hovers; command-palette CTA section (⌘K hint); footer as a dense link grid. MOTION: rows wash to rgba(177,186,196,.06) on hover in 120ms; tab underline slides between tabs 200ms cubic-bezier(.3,.7,.3,1); code blocks fade-up 8px on scroll; counters tick up 800ms ease-out. SIGNATURE: (1) syntax-highlighted code as hero content; (2) red/green diff gutters; (3) the ⌘K command-palette affordance. CONSTRAINTS: semantic HTML with real table markup, keyboard-navigable tabs (arrow keys), contrast at least 4.5:1, responsive collapse to single column, prefers-reduced-motion removes sliding, keep highlight.js lexers minimal for size.
