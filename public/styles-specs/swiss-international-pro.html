Description

Austere light-gray pages ruled by a strict 12-column grid, flush-left ragged-right type, and one decisive red used like a stamp. Use it for studios, agencies, and reports that want authority through restraint. Distinctive because every element — including whitespace — is measurable and aligned.

ROLE: You are a senior front-end engineer building a one-page agency portfolio in the Swiss International Pro style — grid-obsessed, typographic, ruthlessly aligned. LOOK: Palette — bg #FAFAF8, surface #FFFFFF, fg #111111, muted #6B6B6B, accent #E30613, accent2 #1A1A1A, border #E3E3DF, no gradient. Load fonts via https://fonts.googleapis.com/css2?family=Inter+Tight:wght@500;700;800&family=Inter:wght@400;500;600&family=IBM+Plex+Mono:wght@400;500&display=swap — Inter Tight for display, Inter for body, IBM Plex Mono for metadata. Everything flush left; no centered text anywhere except the CTA band. LAYOUT: Build in order: (1) sticky top nav — wordmark left, five mono uppercase links right, 1px #E3E3DF bottom border; (2) hero — 4px red rule, mono kicker, 8-column-clamped Inter Tight headline, gray lede, two buttons; (3) stats band — four columns with oversized numerals and mono labels; (4) feature grid — three white cards on hairline borders with index numerals 01/02/03; (5) about — two flush-left paragraphs; (6) CTA band; (7) footer-mega — four columns of mono links. MOTION: Use GSAP ScrollTrigger: red rules scale-x 0-100% in 500ms cubic-bezier(0.77,0,0.18,1); headlines split-line reveal, 80ms stagger, 600ms each; sections scroll-snap (CSS scroll-snap-type: y proximity); nav underline grows 200ms ease-out. SIGNATURE: A toggleable 12-column grid overlay button (shows semi-transparent red columns); oversized index numerals set in Inter Tight 800 at 4rem. CONSTRAINTS: Semantic HTML (header/main/section/footer), responsive single-column under 720px, WCAG AA contrast (#E30613 only on white/light surfaces), no layout shift, defer JS, total under 150KB.
