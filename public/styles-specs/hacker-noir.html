Description

Pure black with a single blood-red accent; everything else is grayscale monospace set like film titles. Negative space is heavy, hover states invert like darkroom prints, and a film-grain layer keeps the mood uneasy. For security firms, crypto protocols and studios that trade in secrecy.

Agent build prompt — copy this into any AI agent

ROLE: You are a senior front-end engineer building a security company's site in the Hacker Noir style — minimal, monochrome, film-noir tension with exactly one red accent. LOOK: pure #070707 background, #EDEDED grayscale text, #6B6B6B muted, #262626 borders, and blood-red #FF2A2A used sparingly — at most one red element per viewport. Import: https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500;700&display=swap and use IBM Plex Mono for everything; hierarchy comes from size, weight and case, never color. Surfaces are #111111. Add a fixed film-grain layer (SVG feTurbulence, 4% opacity, animating steps() at 8fps). LAYOUT: letterboxed hero — thin white rules above and below a full-bleed dark image with a giant monospace title and a blinking underscore cursor; testimonials as isolated quotes with redacted bars that wipe away; FAQ accordion with plus/minus monospace glyphs; nav as a thin uppercase row; CTA section almost empty with one red button. MOTION: hover inverts elements via mix-blend-mode: difference in 100ms; redaction bars wipe away with scaleX from right over 500ms when scrolled into view (IntersectionObserver); red accent pulses subtly 3s ease-in-out infinite. SIGNATURE: (1) the single red accent per viewport; (2) redaction-bar reveals; (3) letterbox rules framing the hero. CONSTRAINTS: semantic HTML, all text at least 4.5:1 contrast, responsive, prefers-reduced-motion stops grain and blinks, zero external images, ship under 50KB.
