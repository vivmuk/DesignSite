Description

Television sports graphics as a website: lower-third banners slide in with athlete stats, medal tables gleam gold-silver-bronze, and split times animate as horizontal bars. Kinetic condensed type and a confident red-navy-gold palette. The page has an announcer's energy but a statistician's accuracy.

Agent build prompt — copy this into any AI agent

ROLE: You are a broadcast-graphics engineer building for the web. Create a single-page sports results hub in the Olympic Broadcast Stats style. LOOK: Navy bg #0A1F3C, panel #122B52, white text #FFFFFF, muted #8FA6C4, red accent #E8352E, gold #C9A227, border #1E3D6B, gradient `linear-gradient(135deg,#0A1F3C,#16345F)`. Import: <link href="https://fonts.googleapis.com/css2?family=Archivo:wght@600;700;800&family=Inter:wght@400;600;700&display=swap" rel="stylesheet">. Archivo for broadcast display, Inter for stats. LAYOUT: 1) Event header with discipline + session code. 2) Hero lower-third: athlete name, lane, PB in banner form. 3) Results table with medal chips and record tags. 4) Split-time bar comparison (ranked, gold=winner). 5) Medal standings band with count-ups. 6) Upcoming heats ticker. 7) Footer with federation links. MOTION: Lower-thirds slide from left 450ms cubic-bezier(0.16,1,0.3,1) with wipe mask. Split bars grow width 800ms ease-out staggered 100ms by rank. Medal counts roll 900ms. WR/AR tags flash scale 1.15→1 once, 500ms. SIGNATURE: (a) broadcast lower-third banners, (b) metal-chip medal table, (c) ranked split-time bars. CONSTRAINTS: Semantic <table> for results with <th scope>, AA contrast (white on navy passes; red/gold only for accents), lower-thirds trigger once via IntersectionObserver, ticker pauses on hover and reduced-motion; data hardcoded in a JS array (no API needed); responsive: bars keep % widths, table scrolls horizontally with sticky first column. EXTRA: Add lane assignments as a second table column; wind reading appears as a small badge on the results header; ticker items are anchors to the schedule section; medal chips use radial metal gradients.
