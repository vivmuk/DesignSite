Description

Documentation reduced to its atoms: pure black, pure white, and a single monospace voice carrying every heading, paragraph and terminal block. Zero decoration, zero color — hierarchy comes entirely from weight, size and spacing. Built for API docs, infrastructure products and developer platforms where clarity is the whole brand.

Agent build prompt — copy this into any AI agent

ROLE: You are a senior front-end engineer building documentation for an infrastructure API in the Vercel Mono Docs style — monochrome, monospace-only, ruthlessly minimal. LOOK: pure #000000 background, #0A0A0A code surfaces, white #FFFFFF headings, #888888 body text, #333333 hairline borders. NO accent color exists — hierarchy comes from size, weight and spacing only. Import fonts: https://fonts.googleapis.com/css2?family=Geist+Mono:wght@400;500;600&display=swap — Geist Mono is the display, body AND mono face; set body at 15px/1.7, headings at -0.02em tracking. LAYOUT: 56px top bar with wordmark left, ⌘K search trigger right; below, a 3-pane docs shell — 220px mono TOC list, fluid article column (max 720px), 200px right rail of section anchors; article anatomy: h2 sections with block-cursor suffix, code fences with filename header bars ($ deploy.config.yaml), parameter tables with 1px #333333 row rules, callout blocks prefixed 'NOTE:'. Marketing hero is optional; when present keep it three mono lines and one white button. MOTION: deliberately sparse — link underlines grow left-to-right 160ms linear; copy buttons swap label instantly (no fade) and revert after 1.2s; sections fade+rise 8px over 220ms ease-out via IntersectionObserver, firing once; heading cursors blink 1.06s steps(2) infinite. No transforms beyond the reveal, no easing curves beyond linear/ease-out. SIGNATURE: (1) every text element in the same mono face; (2) $ prompt-prefixed terminal blocks with filename bars; (3) blinking block cursor terminating h2s; (4) pure black-white discipline — audit and reject any color. CONSTRAINTS: semantic HTML (nav, main, article, aside); WCAG AAA body contrast (#888888 on black is 7:1+ — verify); keyboard-first TOC navigation; responsive: rails collapse under 900px, article goes full-width with sticky top bar under 640px; prefers-reduced-motion kills blinks and reveals; zero images, zero icon fonts — ASCII glyphs only; ship under 10KB CSS+JS.
