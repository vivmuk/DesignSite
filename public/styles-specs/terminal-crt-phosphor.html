Description

A full-screen CRT terminal simulation: phosphor-green monospace text glows over a near-black screen with drifting scanlines and a blinking block cursor. Panels are framed with ASCII box-drawing borders and copy reads like a boot log. Built for developer tools, CLI products and hacker-adjacent brands that want hardcore credibility.

Agent build prompt — copy this into any AI agent

ROLE: You are a senior front-end engineer building a marketing site for a developer CLI tool in the Terminal CRT Phosphor style — everything on screen must feel like a living green-phosphor terminal. LOOK: near-black #050A06 background, phosphor green #33FF66 primary text, bright #00FF41 accents, muted #1D8A4A labels, borders #1E4D33. Every text element carries text-shadow: 0 0 8px rgba(0,255,65,.45). Import fonts: https://fonts.googleapis.com/css2?family=VT323&family=IBM+Plex+Mono:wght@400;600&display=swap — VT323 for display, IBM Plex Mono for everything else. Add a scanline overlay (repeating-linear-gradient, 6% opacity) and subtle vignette over the whole page. LAYOUT: sticky one-line status bar nav with prompt-prefixed links; full-viewport boot-log hero where the headline types out character-by-character below a fake uptime line; features as three ASCII-bordered panels; about section styled as a terminal transcript; CTA as a giant prompt line 'press [ENTER] to deploy'; footer as a single status row. MOTION: vanilla JS typewriter at 38ms/char with a block cursor blinking 1s steps(2) infinite; scanline overlay drifting 9s linear infinite; phosphor flicker keyframes 0.97–1.03 over 4s; panel hover inverts colors in 120ms ease and prepends '> '. SIGNATURE: (1) ASCII box-drawing borders around every panel; (2) blinking block cursor after every heading; (3) boot-log lines with millisecond timestamps. CONSTRAINTS: semantic HTML5, contrast green-on-black passes WCAG AAA, responsive single column under 768px, prefers-reduced-motion kills flicker and typewriter, no external images, all decorative overlays aria-hidden.
