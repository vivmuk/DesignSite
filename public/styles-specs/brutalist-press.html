Description

Plain white page, black Times-serif headlines, blue underlined links, monospace metadata, and visible page structure — borders and rules left exposed like scaffolding. Use it for zines, manifestos, and art projects. Distinctive because its refusal to style IS the style.

Agent build prompt — copy this into any AI agent

ROLE: Build a manifesto zine site in the Brutalist Press style — the refusal to decorate is the design. Use as little CSS as honesty allows. LOOK: Palette — bg #FFFFFF, surface #FFFFFF, fg #000000, muted #555555, accent #0000EE (default link blue), accent2 #FF0000 (sparingly, for one alert), border #000000. Fonts: system stacks only — display 'Times New Roman', serif; body 'Helvetica Neue', Arial, sans-serif; mono 'Courier Prime', monospace, loaded via https://fonts.googleapis.com/css2?family=Courier+Prime&display=swap — system stacks take precedence over webfonts. No border-radius anywhere. LAYOUT: (1) nav — plain monospace links separated by ' | ', underlined, default blue; (2) ticker — 2px black-bordered marquee, Courier, scrolling 60px/s; (3) hero — huge Times bold uppercase headline flush left, plain paragraph, a blinking underscore; (4) data-table of back issues with fully visible 1px black borders; (5) FAQ as definition lists with hr separators; (6) footer-mega of blue underlined links including 'view source'. MOTION: Hover-invert on links and table rows — background #000, color #FFF, transition 0ms; marquee via CSS keyframes linear infinite; browser-default focus outlines left untouched; one steps(1) blinking cursor at 1Hz. SIGNATURE: The exposed table borders; a footer line reading 'This page uses no JavaScript frameworks. View source.'; red #FF0000 used exactly once, on the 'OUT NOW' alert. CONSTRAINTS: Valid HTML5, works with CSS disabled (progressive enhancement), no external images, AA contrast trivially satisfied, total page under 40KB, zero dependencies.
