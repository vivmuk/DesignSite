Description

One enormous condensed grotesk headline fills the viewport edge to edge; everything else — captions, indexes, links — shrinks to whisper-size around it. Use it for campaigns, poster series, and music releases. Distinctive because there is no imagery: type carries all hierarchy and emotion.

Agent build prompt — copy this into any AI agent

ROLE: Build a campaign / music release site in the Grotesk Type Poster style — type is the entire design; no photography. LOOK: Palette — bg #F2F0EC, surface #FFFFFF, fg #0C0C0C, muted #6E6A64, accent #FF3B00, accent2 #1414FF, border #DEDBD3, no gradient. Load fonts via https://fonts.googleapis.com/css2?family=Anton&family=Archivo:wght@400;500;600&family=IBM+Plex+Mono:wght@400;500&display=swap — Anton for the poster headline, Archivo for everything else, IBM Plex Mono for captions. Headlines: uppercase, line-height 0.9, letter-spacing -0.01em, sized with clamp(4rem,14vw,13rem) so they bleed to the margins. LAYOUT: (1) nav — hairline bottom border, mono links; (2) hero — one viewport-filling Anton word or phrase, rotated vertical caption on the right edge, oversized outline numeral behind; (3) hairline index table (dates/venues/links) with instant hover-invert rows; (4) quote wall — large pull lines in Anton at 3rem; (5) stats band in condensed numerals; (6) footer-mega with a velocity ticker strip. MOTION: Variable-font squeeze — headline font-variation-settings 'wght' maps to scroll velocity via GSAP ScrollTrigger getVelocity; lines mask-reveal upward 700ms, 120ms stagger on load; ticker speed = base 60px/s multiplied by scroll velocity, direction flips on upscroll; table rows invert instantly (0ms) on hover. SIGNATURE: The headline literally touching all four viewport edges; rotated side captions; exactly one blue #1414FF link on the page. CONSTRAINTS: Semantic HTML, headline remains selectable text (no SVG outline text), clamp() prevents overflow at any width, reduced-motion freezes the ticker, AA contrast, no images shipped at all.
