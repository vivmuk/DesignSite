Description

A website that IS an IDE: file-tree rail, tabbed editor with syntax colors, inline terminal panel, minimap gutter, and status bar with branch and line:col. For dev tools, code portfolios, and API explorers that want the page to feel like the working environment. The signature is the editable illusion — the editor looks live, with a blinking cursor in a real code block.

CONSTRAINTS: Semantic HTML (header/main/section/footer), WCAG AA contrast on body text, responsive single column under 760px, no horizontal overflow at 360px, focus-visible outlines on all interactive elements, no layout shift, defer JS.
