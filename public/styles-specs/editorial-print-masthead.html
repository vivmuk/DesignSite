Description

A warm paper-toned page set like a broadsheet: a black-letter masthead, hairline column rules, drop caps opening every essay, and a restrained two-ink palette. Use it for magazines, longform essays, and journals. Distinctive because reading rhythm — not UI chrome — carries the design.

ROLE: You are building a longform magazine homepage in the Editorial Print Masthead style — broadsheet discipline for the browser. LOOK: Palette — bg #FBF7EF, surface #FFFFFF, fg #211C15, muted #6E655A, accent #8C2B2B, accent2 #2F4B38, border #E4DCCC, no gradient. Load fonts via https://fonts.googleapis.com/css2?family=Playfair+Display:wght@500;700;900&family=Source+Serif+4:ital,opsz,wght@0,8..60,400;0,8..60,600;1,8..60,400&family=Courier+Prime:wght@400;700&display=swap — Playfair Display for the masthead and headlines, Source Serif 4 for body at 1.15rem/1.75, Courier Prime for datelines. Drop caps use float + ::first-letter at 3.4em. LAYOUT: (1) Masthead — centered Playfair wordmark between a 3px top rule and 1px bottom rule, dateline slug in Courier Prime; (2) nav — centered small-caps links; (3) lead essay — two CSS columns with 1px #E4DCCC column-rule, drop cap opening; (4) timeline of recent issues; (5) pull quote band; (6) FAQ-style letters-to-the-editor accordion; (7) footer-mega with archive columns. MOTION: GSAP ScrollTrigger + DrawSVGPlugin: rules draw left-to-right 600ms ease-out; drop caps settle from scale 1.05, 700ms; masthead letter-spacing eases .2em to normal on load, 900ms; pull quotes rise 20px, 800ms, triggered at 40% visibility. SIGNATURE: The double-rule dateline band; true column rules between essay columns; a centered pull quote set in italic Playfair between hairlines. CONSTRAINTS: Semantic article/section/figure markup, hyphens:auto with text-wrap:balance on headlines, AA contrast for #6E655A on #FBF7EF, columns collapse to one under 720px, images lazy-loaded.
