Description

Figma's canvas turned into a website: an infinite dotted grid stretches in every direction, sections are frames you pan between, and fake collaborator cursors glide around with name tags — multiplayer as decoration and metaphor. Selection states, zoom controls and measurement labels treat the visitor as a collaborator inside the tool. Definitive for design tools and collaboration products.

Agent build prompt — copy this into any AI agent

ROLE: You are a senior front-end engineer building a landing page for a collaborative design tool in the Figma Canvas Native style — the website itself behaves like an infinite multiplayer canvas. LOOK: light canvas #F5F5F5 covered in a 24px dot grid (radial-gradient dots, #D4D4D4), frames on white #FFFFFF with 1px #E0E0E0 borders, ink #1E1E1E, secondary #6E6E6E, selection/primary blue #0D99FF, orange-red #F24E1E secondary. Import fonts: https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Roboto+Mono:wght@400;500&display=swap — Inter for all UI, Roboto Mono for measurement labels, zoom pill and coordinates. Radii small: 8px frames, 6px controls — this is tooling chrome, not consumer softness. LAYOUT: a top toolbar 48px styled like an editor (logo, tool icons, share button, avatar cluster); hero is a large white frame with the headline inside it, complete with a selection outline + handles and a '1200 × auto' measurement label above; features are three frames in a row, each selectable; a multiplayer strip with live ghost cursors and a comment pin; onboarding steps styled as layers in a layers-panel sidebar motif; CTA frame; minimal footer styled as a status bar (zoom left, page name center, collaborators right). MOTION: background dot grid pans opposite the mouse at rate 0.03 via rAF lerp 0.1 — infinite canvas depth; 3 ghost cursors ease toward random waypoints (lerp 0.04, new waypoint every 4-9s) with name tags in #0D99FF/#F24E1E/#8A38F5; clicking any frame draws a selection box whose dashed border march-ants at 20 steps/s; zoom pill recalculates percentage from scroll (clamped 50–150%), click smooth-scrolls to top in 400ms. SIGNATURE: (1) the dotted infinite grid with mouse parallax; (2) selection boxes with corner handles + march-ants on interactive frames; (3) ghost multiplayer cursors that never stop; (4) mono measurement labels and live zoom percentage. CONSTRAINTS: semantic HTML; WCAG AA contrast on all frame text; selection visuals are decorative — keep real focus states separate and visible; responsive: toolbar collapses to logo+share under 800px, parallax and ghost cursors disabled on touch/reduced-motion; ghost cursors aria-hidden; canvas pan never causes horizontal scroll (overflow hidden, will-change on one layer); total JS < 15KB.
