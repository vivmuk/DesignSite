Description

Built like a webtoon reader: vertical scroll-snap panels that read as episodes, pastel pink-teal gradients, and UI furniture drawn as speech bubbles with tails. Perfect for entertainment, comics, and youth apps that want serialized storytelling. The signature is content presented as comic panels — rounded frames, bubble buttons, and episode counters.

Agent build prompt — copy this into any AI agent

ROLE: Build a single-page site for a webtoon/entertainment platform in the Korean Pastel Webtoon style. LOOK: background #FFF7FA with a pastel linear-gradient(#FFF0F6,#EAF9FB) wash, white panels, text #3A2E44, muted #9B8AA6, accents #FF7EB6 (bubble pink) and #7ED0D6 (mint), border #F2DCE8. Load https://fonts.googleapis.com/css2?family=Jua&family=Noto+Sans+KR:wght@400;500;700&display=swap — Jua for display, Noto Sans KR for body. LAYOUT in order: (1) sticky header with rounded logo chip and pill nav; (2) hero: giant speech-bubble headline with CSS tail, subtitle, two bubble-shaped buttons, and a row of comic panel thumbnails; (3) scroll-snap episode strip of 3–4 full-height panels each with an EP chip and caption bubble; (4) feature grid of three rounded cards for genres or apps; (5) about blurb with floating stickers; (6) pink CTA band styled as a rounded panel; (7) footer. MOTION: bubbles pop in with scale 0.6→1.04→1 over 320ms spring easing; use CSS scroll-snap with a sticky progress dot rail; add infinite typing-dots animation (three dots, 150ms stagger); stickers tilt ±6deg on hover over 250ms. SIGNATURE: (a) all primary buttons are speech bubbles with tails, (b) an EP.01-style episode chip system, (c) floating sparkle decorations. CONSTRAINTS: semantic HTML, 4.5:1 text contrast, single column below 760px, no JS frameworks, CSS-only motion, images lazy-loaded. DELIVERY: Ship one self-contained index.html. Define CSS custom properties --bg:#FFF7FA, --surface:#FFFFFF, --fg:#3A2E44, --muted:#9B8AA6, --accent:#FF7EB6, --accent2:#7ED0D6, --border:#F2DCE8 on :root and use them everywhere — no hard-coded colors. Preconnect to fonts.googleapis.com and fonts.gstatic.com, load Jua, Noto Sans KR with display=swap and a system-font fallback stack to prevent layout shift. Implement the motions (bubble pop, episode snap, typing dots, sticker tilt) exactly as specified; wrap every ambient loop in @media (prefers-reduced-motion: reduce) to disable. Verify before delivery: all headings in a logical h1→h3 order, focus-visible outlines on interactive elements, no horizontal overflow at 360px viewport, and images with width/height attributes to avoid CLS.
