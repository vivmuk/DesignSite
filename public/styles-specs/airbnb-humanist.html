Description

Airbnb's humanist language: photography-forward cards with Cereal-style rounded type, a warm coral accent used with discipline, and infinite carousels that invite browsing forever. Whitespace is generous but cozy — the page feels like a host welcoming you in. Purpose-built for marketplaces, travel and communities where trust and warmth must coexist with transactional clarity.

Agent build prompt — copy this into any AI agent

ROLE: You are a senior front-end engineer building a travel marketplace in the Airbnb Humanist style — warm, photographic, trustworthy, transactionally crisp. LOOK: white #FFFFFF base, soft gray #F7F7F7 surfaces, ink #222222, secondary #717171, hairlines #DDDDDD. Coral #FF385C is reserved for the wordmark, save-hearts and one primary CTA — never for text fills. Teal #00A699 marks availability and success. Import fonts: https://fonts.googleapis.com/css2?family=Nunito:wght@600;700;800&family=Nunito+Sans:wght@400;600&display=swap — Nunito 700–800 for headings and buttons (Cereal stand-in), Nunito Sans for body. Border radius: 16px cards, 999px pills, 8px small controls. LAYOUT: transparent-over-photo sticky nav that gains white bg on scroll: logo, pill search 'Where to? — Add dates — Add guests' center, 'Become a host' + avatar right; hero is an edge-to-edge photo with the search pill floating over it; below, a filter-chips row then a responsive listing grid (aspect-ratio 4/3 photos, heart button top-right, title/location/rating/dates/price lines); infinite-feel carousels per category; a 'host' promo band; mega footer. MOTION: carousels drag with pointer events (momentum friction 0.92, 320ms ease-out snap, cloned edges for infinite loop); heart pop 1→1.3→1 over 260ms cubic-bezier(.3,1.4,.5,1) filling coral; card photos zoom 1.08 over 280ms ease-out on hover; search pill expands to a full panel 280ms ease-out with 60ms-staggered child fades. Vanilla JS only. SIGNATURE: (1) photography leads — every card is 70% image; (2) coral gradient used sparingly for brand moments only; (3) rounded humanist type on everything; (4) the bouncy heart as the emotional signature. CONSTRAINTS: semantic HTML (nav, main, article, ul lists); WCAG AA — #717171 on white passes; hearts are <button aria-pressed>; carousels keyboard-accessible (arrow keys) with visible focus; responsive: 4-col grid → 2 → 1; nav search collapses to icon under 900px; prefers-reduced-motion disables momentum and pops; images lazy-loaded with LQIP placeholder backgrounds; total JS < 18KB.
