Description

The Stripe school: airy weight-300 display type floating over animated mesh gradients of indigo and cyan, with real product UI and code snippets given equal billing. Trust is engineered through precision — generous spacing, exact alignment, restrained motion. The definitive style for fintech, payments and API-first SaaS that must feel both cutting-edge and bank-grade safe.

Agent build prompt — copy this into any AI agent

ROLE: You are a senior front-end engineer building the marketing site for a payments API in the Stripe Fintech Clean style — airy, precise, trustworthy, code-forward. LOOK: deep navy #0A0B1E base, raised surfaces #12142E, text #E8EAF6 with muted #9FA3C8, hairlines #23264A, signature indigo #635BFF accent and cyan #00D4FF secondary. Import fonts: https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&family=Inter+Tight:wght@300;400&family=Fira+Code:wght@400;500&display=swap — Inter Tight at weight 300 for display (clamp 2.6–4.5rem, -0.03em tracking), Inter 400 for body, Fira Code for all code and metric labels. The hero backdrop is a mesh gradient: three blurred (80px) radial blobs in indigo/cyan/violet drifting slowly. LAYOUT: 64px translucent sticky nav (backdrop-blur 12px) with product dropdowns and a gradient 'Start now' button; full-viewport hero split 50/50 — left: weight-300 headline, one paragraph, dual CTA (solid indigo + ghost), compliance badge row; right: a code card showing a charge creation snippet with syntax colors. Below: 4-column feature grid, a stats band with three count-up numbers (tabular-nums), an about strip with logos row, mega footer with 5 link columns. MOTION: mesh blobs drift on 26s/34s/42s ease-in-out infinite alternate; numbers count 0→target over 1.1s cubic-bezier(.2,.8,.2,1) triggered at 40% viewport via IntersectionObserver; hero code types at 24ms/char with blinking caret; feature cards lift -4px over 200ms ease-out with border-color transition. Vanilla JS only, no animation library. SIGNATURE: (1) the mesh gradient trio behind hero; (2) code snippet and product mock given equal billing in the split hero; (3) weight-300 display typography; (4) PCI/SOC2/ISO badge trust row directly under CTAs. CONSTRAINTS: semantic HTML5 landmarks; WCAG AA on all text (verify #9FA3C8 on #12142E); responsive split hero stacks under 900px, grid becomes single column under 640px; prefers-reduced-motion freezes blobs and disables typewriter/count-up (render final values); font-display swap with size-adjust fallbacks to prevent CLS; lazy-load nothing above fold; total JS < 20KB.
