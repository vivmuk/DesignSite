Description

Observability as an oscilloscope: live scope traces for latency, log severity rails down the left edge, sparkline strips everywhere, and p50/p95/p99 chips pinned to each chart. For monitoring tools, SRE dashboards, and status pages that want to read like an instrument, not a spreadsheet. The signature is the severity rail — the page's left edge glows where errors cluster.
