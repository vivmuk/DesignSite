Description

Rave-flyer chaos disciplined into a layout: acid smileys, type warped and rotated beyond recognition, and a strobe palette of acid green, hot magenta and UV purple. Kinetic typography pulses to an implied 140 BPM and hover states glitch like a broken VJ feed. For events, music acts and streetwear that need pure serotonin on a webpage.

ROLE: You are a senior front-end engineer building an event/rave site in the Acid Rave Graphics style — flyer chaos, strobe palette, kinetic energy, but a working ticket flow underneath. LOOK: near-black #0D0D0D base, raised #1A1A1A, acid green #F2F207 is the primary voice, magenta #FF1AAD and UV cyan #00F0FF the strobe pair, border #3A3A10. Import fonts: https://fonts.googleapis.com/css2?family=Rubik+Glitch&family=Space+Grotesk:wght@400;500;700&family=Space+Mono:wght@400;700&display=swap — Rubik Glitch ONLY for hero/section display (it's barely legible, that's the point, but keep body fully readable), Space Grotesk for everything functional, Space Mono for timestamps. Headlines rotate ±2deg and can overlap. LAYOUT: skewed top marquee (dates + lineup); nav with smiley logo and TICKETS button in acid green; hero = giant glitch headline + event card (date/venue/age in a bordered flyer block) + TICKETS CTA; lineup section as alternating-direction skewed marquee rows; 'practical info' as a bordered data table (age/doors/cloak/last entry); ticket tiers as perforated stubs; footer as flyer back with fake credits. MOTION: headline pulses scale 1→1.06 on a 429ms half-beat (140 BPM) ease-in-out infinite alternate; hover on headings fires RGB-split glitch — ::before/::after clones in magenta/cyan offset ±3px flickering steps(2) for 300ms; marquees loop 12s linear with rows skewed ±2deg; clicking any CTA spins the nearest smiley 360° with 500ms bounce. Vanilla JS minimal. SIGNATURE: (1) acid smileys as wayfinding; (2) strobe palette discipline — green for actions, magenta/cyan for chaos; (3) perforated ticket-stub dividers (dashed borders + notch cutouts); (4) BPM-synced type pulse. CONSTRAINTS: semantic HTML; body text contrast — #F2F207 on #0D0D0D is 15:1+, but verify #8C8C3A only on large text; marquee content duplicated for screen readers is aria-hidden with an offscreen readable list; flashing/glitch effects capped (no full-screen strobe — WCAG 2.3.1 three-flashes rule); responsive: marquees slow down on mobile, table stacks under 700px; prefers-reduced-motion kills pulse/glitch/marquee (static lineup list shown); total JS < 8KB.
