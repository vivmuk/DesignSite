Description

An analyst's cockpit: every cell earns its place, sparklines inline with figures, dense filter rails, and export buttons within reach. Slate-and-teal dashboard palette with tabular numerals and disciplined 8px spacing. Built for BI, research, and anyone who says 'just show me the table'.

LOOK: Slate bg #F4F6F8, white surface #FFFFFF, ink #1F2933, muted #6B7785, teal accent #0E7C86, signal orange #E86A33, border #D9E0E7, no gradients. Import: <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500&display=swap" rel="stylesheet">. Inter for UI, JetBrains Mono with tabular-nums for every figure. LAYOUT: 1) Top bar: workspace name, saved-views dropdown, export button. 2) KPI strip: four stat cards with deltas. 3) Main split: left filter rail (facets, range sliders), right data table with sparkline column, sortable headers, sticky first column. 4) Right detail drawer opens on row click with a line chart. 5) Pagination footer with rows-per-page. MOTION: uPlot sparklines draw 500ms ease-out on intersection. Filter changes re-render rows with 250ms fade + 20ms stagger. Sort arrow rotates 200ms. SIGNATURE: (a) inline sparkline column, (b) faceted filter rail with live result counts, (c) export dropdown that actually triggers a CSV download client-side. CONSTRAINTS: Semantic <table> + <button aria-sort>, row virtualization past 500 rows, keyboard: arrows navigate cells, `f` focuses filters; AA contrast; responsive: filter rail collapses to a drawer under 1024px; debounce filters 150ms; no external chart bloat — uPlot is ~40KB.
