Description

The property-search workhorse: a live map filling half the screen, synced cards sliding on the other half, price pills pinned to every parcel. Hover a card, the pin pulses; move the map, cards reorder. Practical modernism — clean tiles, clean type, and zero ambiguity about what costs what.

Agent build prompt — copy this into any AI agent

ROLE: You are a proptech front-end engineer. Build a single-page property search in the RealEstate Map Modern style. LOOK: Pale bg #F7F8F7, white cards #FFFFFF, ink #1D2733, muted #64748B, forest accent #1E6E5C, coral highlight #E85D3D, border #E2E8E6, no gradients. Import: <link href="https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;700&display=swap" rel="stylesheet">. DM Sans with tabular-nums for prices. LAYOUT: 1) Toolbar: location input, bed/bath/price chips, save-search, map toggle. 2) Split body: left map with custom price-pill markers; right virtualized card list (photo, price, beds/baths/sqft, heart). 3) Hover sync both directions. 4) Mobile: map toggles full-screen, filter bottom-sheet. MOTION: Hover pin pulse scale 1→1.3→1 600ms both ways. Cards slide in 350ms cubic-bezier(0.22,1,0.36,1) staggered 40ms on new results. Price pills fade-scale 250ms post tile-load. Filter sheet springs 400ms with overshoot. SIGNATURE: (a) price pills as map markers, (b) two-way card↔pin hover sync, (c) draw-on-map boundary search. CONSTRAINTS: Semantic <ul> of results with <article> cards, all interactive elements keyboard-reachable, map has text alternative list; virtualize past 60 cards; debounce map-move queries 400ms; cluster markers past 200; AA contrast; lazy tile + image loading; heart state persists to localStorage. EXTRA: Price pill markers are DOM buttons with aria-labels like '749000 dollars, 3 bed on 9th'; map and list scroll independently; a compare-tray holds up to three saved cards at the bottom.
