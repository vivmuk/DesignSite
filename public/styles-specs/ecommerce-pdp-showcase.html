Description

A product-detail kit done properly: gallery with pinch-free zoom lens, size selector rows with stock states, sticky buy bar that rises on scroll, and an accordion of materials and shipping. For e-commerce, DTC, and marketplaces that treat the PDP as the store's front door. The signature is a confident, quiet layout that makes one product feel enormous.

ROLE: Build a single-page product detail page in the Ecommerce PDP Showcase style. LOOK: background #FFFFFF, warm-gray panels #F6F5F2, near-black text #191919, muted #74716B, accents #1A1A1A (primary buttons) and #C96F4A (terracotta highlights), border #E6E4DF. No gradients — restraint is the look. Load https://fonts.googleapis.com/css2?family=Archivo:wght@500;700&family=Inter:wght@400;500;600&display=swap — Archivo display, Inter body. LAYOUT: (1) slim header with cart icon; (2) PDP split — left 60% gallery with main image, zoom lens on hover, thumbnail strip beneath; right 40%: Archivo title, price, rating row, size selector chips (one sold-out with strike), quantity stepper, add-to-cart button, trust row of three icons; (3) accordion for materials, shipping, returns; (4) review histogram with bars; (5) related-products row of three product cards; (6) footer. MOTION: hover shows a 2× zoom lens over 120ms ease-out; thumbnails crossfade the main image 250ms with scale 1.02→1; a sticky buy bar (price, size, CTA) rises from the bottom over 320ms cubic-bezier(0.22,1,0.36,1) once the hero CTA leaves view; the chosen size chip pulses its ring once for 300ms. SIGNATURE: (a) sticky buy bar, (b) zoom lens gallery, (c) sold-out strike chips. CONSTRAINTS: semantic HTML, 4.5:1 contrast, single column stacking gallery above buy-box below 800px, keyboard-operable accordion, lazy-load images. DELIVERY: Ship one self-contained index.html. Define CSS custom properties --bg:#FFFFFF, --surface:#F6F5F2, --fg:#191919, --muted:#74716B, --accent:#1A1A1A, --accent2:#C96F4A, --border:#E6E4DF on :root and use them everywhere — no hard-coded colors. Preconnect to fonts.googleapis.com and fonts.gstatic.com, load Archivo, Inter with display=swap and a system-font fallback stack to prevent layout shift. Implement the motions (zoom lens, thumb crossfade, buy bar rise, size pulse) exactly as specified; wrap every ambient loop in @media (prefers-reduced-motion: reduce) to disable. Verify before delivery: all headings in a logical h1→h3 order, focus-visible outlines on interactive elements, no horizontal overflow at 360px viewport, and images with width/height attributes to avoid CLS.
