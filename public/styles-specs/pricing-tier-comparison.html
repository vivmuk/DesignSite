Description

Load https://fonts.googleapis.com/css2?family=Manrope:wght@400;600;800&family=JetBrains+Mono:wght@600&display=swap — Manrope everywhere, JetBrains Mono for prices. LAYOUT in order: (1) header with logo and nav; (2) pricing hero: centered headline, subcopy, monthly/annual CSS toggle with a 'save 20%' badge; (3) three tier cards — middle card elevated with indigo border and floating 'Most popular' badge; (4) full feature matrix comparing 12 capabilities with check/dash cells; (5) testimonial strip; (6) FAQ accordion with five items; (7) footer. MOTION: hovered cards lift 6px over 220ms ease-out; the toggle knob slides with 180ms spring and prices crossfade 200ms; matrix checks pop in scale 0→1.15→1 with 40ms stagger; the badge bobs ±3px over 2.4s. SIGNATURE: (a) raised featured middle card, (b) tabular-mono price numerals that never jitter on toggle, (c) the complete check matrix. CONSTRAINTS: semantic HTML (table for matrix), 4.5:1 contrast, single column stacking cards below 760px, keyboard-operable toggle, no frameworks. DELIVERY: Ship one self-contained index.html. Define CSS custom properties --bg:#FFFFFF, --surface:#F7F8FC, --fg:#171A2B, --muted:#6A7086, --accent:#5B5BF0, --accent2:#00C2A8, --border:#E4E6F0 on :root and use them everywhere — no hard-coded colors. Preconnect to fonts.googleapis.com and fonts.gstatic.com, load Manrope, Manrope, and JetBrains Mono with display=swap and a system-font fallback stack to prevent layout shift. Implement the motions (tier lift, toggle slide, check pop, badge bob) exactly as specified; wrap every ambient loop in @media (prefers-reduced-motion: reduce) to disable. Verify before delivery: all headings in a logical h1→h3 order, focus-visible outlines on interactive elements, no horizontal overflow at 360px viewport, and images with width/height attributes to avoid CLS.
