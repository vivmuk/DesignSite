Description

Healthcare-grade clarity: crisp whites, a single calming teal, animated line icons that explain procedures in one glance, and copy vetted for plain language. Every state is explicit — scheduled, confirmed, complete. Accessibility is not a checkbox here; it is the design language.

Agent build prompt — copy this into any AI agent

ROLE: You are a healthtech UI engineer with an accessibility mandate. Build a single-page clinic site in the Clinical White Medical style. LOOK: Near-white bg #FAFCFD, white surface #FFFFFF, deep teal-ink #16323B, muted #5E7A85, clinical teal #0E7C9E, confirmation green #3BA272, border #D7E4EA, no gradients. Import: <link href="https://fonts.googleapis.com/css2?family=Source+Sans+3:wght@400;600;700&display=swap" rel="stylesheet">. Source Sans 3 only; hierarchy via weight and size. LAYOUT: 1) Accessible nav with skip-link. 2) Hero: stroke-drawn icon + headline + single BOOK APPOINTMENT CTA. 3) Patient-flow stepper (3 steps with connectors). 4) Services grid of line-icon cards. 5) Insurance & billing callouts with teal left rules. 6) FAQ accordion. 7) Trust footer: accreditations, privacy, contact. MOTION: Icons stroke-draw 800ms ease-in-out via dashoffset on intersection. Stepper connector eases width 300ms per step. Status pills pop scale 0.9→1 200ms. Cards float ±4px 6s (disable on reduced-motion). SIGNATURE: (a) stroke-drawn icon system, (b) status pill vocabulary (scheduled/confirmed/complete), (c) teal left-rule callouts in plain language. CONSTRAINTS: WCAG 2.2 AA minimum: 4.5:1 body contrast, focus-visible rings, 48px touch targets, aria-live for status changes; semantic headings h1→h2→h3; forms with labels + inline errors; responsive: stepper becomes vertical under 640px; zero decorative animation without reduced-motion support. EXTRA: Add a printable visit-prep checklist section; phone numbers are tel: links; every service card links to a plain-language detail page stub; ensure headings skip no levels; test with keyboard only.
