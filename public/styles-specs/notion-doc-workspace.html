Description

The doc-tool aesthetic everyone knows: a paste-like canvas, callout blocks with icons, slash-command hints, emoji page covers, toggle lists, and pastel text highlights. Built for SaaS docs, internal wikis, and productivity tools that want to feel like the tool people already live in. The signature is the slash hint — a ghost command palette appearing wherever you focus.
