Description

The entire page speaks in messenger idiom: content arrives as chat bubbles, the messenger launcher is ever-present, and sections read like threaded conversations between brand and visitor. Friendly rounded type, soft spring motion, and typing-indicator moments make the site feel alive and answerable. Built for support products, SaaS onboarding and community platforms.

Agent build prompt — copy this into any AI agent

ROLE: You are a senior front-end engineer building a support-platform marketing site in the Intercom Conversational style — the page itself is a friendly chat conversation. LOOK: white #FFFFFF base, chat surfaces #F2F6FB, ink #1F2A44, secondary #5B6B8C, borders #DCE4F0, primary blue #2D6FF7, success teal #28C76F. Import fonts: https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&family=JetBrains+Mono:wght@400&display=swap — Manrope everywhere (800 display, 400 body); JetBrains Mono only for timestamps. Radii are chat-native: bubbles 18px (14px on sender-corner), buttons 12px, FAB circular. LAYOUT: slim 60px nav with logo, links and 'Start free' gradient pill; hero staged AS a chat: a phone-frame-style panel where brand bubbles and user bubbles alternate telling the product story, ending with a quick-reply chip row; the real CTA lives in chat ('[ Book a demo ]' as a chip); following sections are 'threads' — each opens with a brand bubble (headline) and answers with user bubbles (feature bullets); FAQ is a conversation with expandable reply bubbles; footer keeps a slim chat-echo bar. MOTION: bubbles spring in on scroll — translateY(14px) scale(.95)→1 over 320ms cubic-bezier(.34,1.4,.5,1), 140ms stagger; before each brand bubble a 3-dot typing indicator bounces (900ms cycle, 120ms stagger) then swaps; the messenger FAB idles at ±4px bob every 3s and its panel springs from bottom-right 0.9→1 over 220ms; read receipts shift ✓→✓✓ in teal 800ms after a user bubble lands. Vanilla JS + CSS only. SIGNATURE: (1) the entire narrative told in alternating chat bubbles; (2) persistent messenger launcher with opening panel; (3) typing dots before every brand reply; (4) quick-reply chips as navigation/CTA. CONSTRAINTS: semantic HTML — chat is a real conversation (use role='log' aria-live='polite' for the chat region); WCAG AA contrast; FAB opens a real focusable panel (Esc closes, focus returns); responsive: chat panel goes full-width under 640px, nav collapses; prefers-reduced-motion removes springs/bobbing and shows all bubbles instantly; no external images — avatars are colored initials; total JS < 14KB.
