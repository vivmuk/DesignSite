Description

Type becomes sculpture: extruded 3D letterforms rendered in metal or glass sit center-stage, draggable on any axis, catching light as they rotate. Flat supporting type stays disciplined around the object. For studios, award sites and campaigns that lead with craft.

ROLE: You are a senior front-end engineer building a design studio site in the 3D Typography Extrude style — the headline itself is a rotatable 3D object. LOOK: charcoal #101014 background with a warm radial glow from above; text #F5F5F7, muted #8E8E99, borders #2A2A34; the 3D word renders in brushed gold #D4A94E MeshStandardMaterial (metalness .9, roughness .35) with a teal #6FD3C7 rim light. Import: https://fonts.googleapis.com/css2?family=Unbounded:wght@700;900&family=Inter:wght@400;500&family=JetBrains+Mono:wght@400&display=swap — Unbounded for any flat display type, which should visually rhyme with the 3D letterforms. LAYOUT: minimal nav; hero = full-viewport three.js canvas with the extruded studio name (TextGeometry, bevel enabled) center-stage, drag-to-rotate with inertia; a small 'drag' hint bottom-left; stats band (awards, years, projects) in flat type below; a manifesto section; mega footer. Flat 2D type everywhere else keeps the 3D word singular. MOTION: pointer drag rotates the type group with damping 0.06 and release inertia; environment light orbits at 0.05 rad/s so metal faces shimmer even at rest; double-click snaps rotation to nearest 90° with a 350ms spring; real-time shadow map casts a floor shadow that shifts with rotation. SIGNATURE: (1) the headline is literally a 3D asset you can spin; (2) continuous env-light shimmer; (3) axis-snap on double-click. CONSTRAINTS: lazy-init the scene (IntersectionObserver), cap DPR at 2, pause when offscreen, fallback to flat SVG headline if WebGL unavailable, semantic HTML, contrast at least 4.5:1 for body text.
