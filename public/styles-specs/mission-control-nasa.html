Description

Flight-control room aesthetics: warm amber phosphor readouts, vector-line plot graphics and grid-lined console panels on deep brown-black. Data always looks live — counters tick, telemetry lines redraw, clocks count mission time. Built for aerospace brands, data products and technical docs that want mission-critical gravitas.

Agent build prompt — copy this into any AI agent

ROLE: You are a senior front-end engineer building a data-platform marketing site in the Mission Control NASA style — the page must feel like a live 1970s flight-control console, amber phosphor and all. LOOK: deep brown-black #120B02 background, amber #FFB000 primary readouts, bright #FF8C00 accents, cream #FFE0A3 highlights, borders #3D2A08. All numerals monospaced with font-variant-numeric: tabular-nums. Import: https://fonts.googleapis.com/css2?family=VT323&family=Share+Tech+Mono&display=swap — VT323 for giant display digits, Share Tech Mono everywhere else. Console panels sit on #1C1204 surfaces with 2px bezel borders and small-caps labels like 'TELEMETRY — CH 04'. LAYOUT: top bar with MET elapsed clock (ticks every second) and nav; hero split 60/40 — huge amber count-up KPIs left, live vector-plot chart right; stats band of five console tiles; data table of mission events; timeline of mission milestones as console steps; CTA framed as an 'AUTHORIZE LAUNCH' console switch panel; footer as a console bank. MOTION: KPIs count up 1.2s ease-out on scroll into view (IntersectionObserver); SVG chart polylines draw via stroke-dashoffset 1.6s ease; GO/NO-GO lamps blink 1.4s steps(2); MET clock ticks live. SIGNATURE: (1) bezel-framed console panels with small-caps labels; (2) vector-line plots drawn live; (3) the always-ticking MET clock. CONSTRAINTS: semantic HTML, amber on brown-black meets WCAG AA minimum (use #FFE0A3 for small text), responsive stacks on mobile, prefers-reduced-motion stops blink and count-up, no heavy frameworks.
