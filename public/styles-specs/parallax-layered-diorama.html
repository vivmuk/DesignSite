Description

An illustrated diorama built from six or more depth layers — sky, ridges, trees, characters, foreground silhouettes — each scrolling at its own speed so the scene has real dimensional depth. Warm daylight palette and storybook serif make it feel hand-built. Perfect for tourism, narrative brands and game worlds.

ROLE: You are a senior front-end engineer building an illustrated tourism page in the Parallax Layered Diorama style. Ship one polished, self-contained page. LOOK: Hand-built storybook daylight. Palette hexes exactly: bg #fdf6ec, surface #ffffff, fg #332f28, muted #8a8176, accent #e8833a (sunset orange), accent2 #4a90a4 (ridge blue), border #ecdcc6, gradient linear-gradient(180deg, #fbe3c2 0%, #fdf6ec 70%) for the sky. Fonts: load https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght@9..144,500;9..144,700&family=Karla:wght@400;600&display=swap — Fraunces for display and signage, Karla for body. All artwork as inline SVG layers, no photography. LAYOUT, in order: (1) top nav over the sky; (2) hero diorama: six stacked SVG layers (sky+sun, far ridges, mist band, mid pines, cabin card, foreground silhouette) filling ~60vh with title and CTA floating in the sky and a hand-lettered trail signpost; (3) seasons feature grid of three cards; (4) a testimonial wall styled as carved-wood quotes; (5) about block 'A hand-built scene'; (6) cabin-reservation CTA band in accent orange; (7) mega footer with trail-map style link columns. MOTION: GSAP ScrollTrigger translates the six layers at 0.08×–0.6× scroll speed (scrub true, farthest slowest). The sun arcs 90° across the first 150vh of scroll while the light warm-shifts. Cloud layer drifts x ±3% on a 14s ease-in-out loop. Foreground critters scale-blink 1→1.06→1 every 4s from transform-origin bottom. SIGNATURE: (a) the readable six-layer depth stack with mist between planes; (b) the sun arc that shifts color temperature; (c) hand-lettered trail signage as UI furniture. CONSTRAINTS: Build responsively with breakpoints at 768px and 1200px; keep all text at WCAG AA contrast (4.5:1 body, 3:1 large); use semantic HTML (header, nav, main, section, article, footer) with descriptive headings; lazy-load below-fold images, defer JavaScript, and keep total JS under 120KB gzipped; ensure every interactive element is keyboard-reachable with a visible :focus-visible state; respect prefers-reduced-motion by freezing layers at rest positions.
