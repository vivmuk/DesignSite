Description

A supply chain alive on screen: animated arcs drawing between ports and warehouses, hub nodes pulsing with throughput, and a fleet status sidebar ticking with ETAs. Deep navy chartroom aesthetic with signal orange for movement. The map is the product; everything else supports it.
