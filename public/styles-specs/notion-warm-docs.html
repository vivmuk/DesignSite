Description

A warm off-white canvas where content is the interface: emoji stand in for icons, generous whitespace breathes between sections, and gentle page-view transitions make navigation feel like flipping paper. Typography is friendly and rounded, hierarchy is soft but unmistakable. Ideal for docs, wikis and community hubs that want to feel human without getting cute.

Agent build prompt — copy this into any AI agent

ROLE: You are a senior front-end engineer building a documentation wiki in the Notion Warm Docs style — warm, human, content-first, zero chrome. LOOK: warm paper #FBF9F4 background (fade to #F5F0E6 at page bottom), white #FFFFFF cards, ink #2F2B26 headings, muted #78716A body-secondary, borders #E8E2D6, coral #C96F4A links, sage #5B8A72 for tags/success. Import fonts: https://fonts.googleapis.com/css2?family=Lora:wght@500;600&family=Karla:wght@400;500;700&family=IBM+Plex+Mono:wght@400&display=swap — Lora 600 for headings, Karla for body (16px/1.7), IBM Plex Mono for inline code. Emoji ARE the icon system — 📘 docs, 💡 tips, ✅ done, 🧭 nav; never use an icon font. LAYOUT: top bar 60px with wordmark, rounded pill search field, and 'New page' button; below, 240px TOC sidebar (paper-tone, pill highlight on active entry) + 720px content column with 96px section rhythm; content anatomy: emoji-prefixed h2s, tip callouts (soft #F0E9DC, 12px radius, 💡 label), checklist blocks (✅), inline mono chips. End with a warm CTA band and 4-column footer. MOTION: page/route swaps use the View Transitions API — 100ms fade out, incoming rises 10px over 200ms cubic-bezier(.3,.7,.4,1); emoji bullets nudge scaleX(1.25) rotate(-6deg) 180ms spring on item hover; callouts slide in 12px from left + fade over 240ms ease-out via IntersectionObserver once; the TOC active pill slides between entries over 180ms. Vanilla JS + CSS only. SIGNATURE: (1) emoji as the entire icon system; (2) warm paper texture and cream fade; (3) serif-over-sans typographic pairing; (4) generous whitespace as the primary luxury signal. CONSTRAINTS: semantic HTML (nav, main, article, aside); WCAG AA — verify #78716A on #FBF9F4 ≥ 4.5:1 for body-sized text; emoji get aria-labels when informative; responsive: TOC collapses to a sticky top-chip row under 900px; prefers-reduced-motion kills transitions and reveals; system emoji rendering means no emoji webfont; total payload under 120KB.
