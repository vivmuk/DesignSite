Description

Headlines behave like objects with mass: split into lines or words, they fly in with scroll velocity, skew under speed and settle with friction. Variable font weight breathes with the scroll. Off-white paper, two loud inks and zero photography put all the drama into the letterforms themselves.

Agent build prompt — copy this into any AI agent

ROLE: You are a senior front-end engineer building an agency campaign page in the Kinetic Type Momentum style. Ship one polished, self-contained page. LOOK: Pure typographic poster energy, zero photography. Palette hexes exactly: bg #f5f1e8, surface #ffffff, fg #121212, muted #7a746a, accent #ff3b1f (poster red), accent2 #1f44ff (ultramarine), border #e5ded0. Fonts: load https://fonts.googleapis.com/css2?family=Anton&family=Space+Grotesk:wght@400;500;700&family=Space+Mono:wght@400&display=swap — Anton for viewport-filling display lines (uppercase, line-height .95), Space Grotesk for body and chips, Space Mono for footer strips. Pair solid and outlined type: outline lines use -webkit-text-stroke 2px in accent2 with transparent fill. LAYOUT, in order: (1) minimal top bar with wordmark and four links; (2) hero: three stacked Anton display lines filling the viewport — one near-black, one solid red, one outlined blue — mid-skew as if moving; (3) services section as inverted-on-hover chips (BRAND, FILM, TYPE, MOTION, WEB) plus an oversized accent numeral; (4) stats band with two huge mono figures; (5) a marquee strip of campaign words; (6) studio about block in narrow measure; (7) CTA: giant Anton line acting as the button itself; (8) footer with mono sign-off. MOTION: Scroll velocity (Lenis) drives skewY ±6° and letter-spacing on display lines, springing back at stiffness 0.9 when idle. GSAP SplitText flies each line up 120% with 0.06s stagger and power4.out per section. A variable-font wght axis sweeps 400→900 across the hero scrubbed to scroll. Chips invert fg/bg in 120ms on hover with a 2px translate kick. SIGNATURE: (a) outlined + solid type pairs on adjacent lines; (b) velocity-driven skew that makes type feel heavy; (c) oversized accent index numerals anchoring sections. CONSTRAINTS: Build responsively with breakpoints at 768px and 1200px; keep all text at WCAG AA contrast (4.5:1 body, 3:1 large); use semantic HTML (header, nav, main, section, article, footer) with descriptive headings; lazy-load below-fold images, defer JavaScript, and keep total JS under 120KB gzipped; ensure every interactive element is keyboard-reachable with a visible :focus-visible state; respect prefers-reduced-motion by disabling scroll-driven animation.
