Description

A messenger component kit: rounded chat bubbles with tails, springy entrance physics, typing dots, emoji reactions, read receipts, and thread branching. For support desks, social apps, and AI assistants that need conversation to feel alive. The signature is timing — bubbles, dots, and reactions all breathe like a real chat.

Agent build prompt — copy this into any AI agent

ROLE: Build a single-page messenger interface in the Chat Bubble Messenger style. LOOK: background #ECEFF4 with a soft gradient, white panels, text #22252B, muted #7C838F, accents #0B93F6 (outgoing blue) and #E4E9F0 (incoming tint), border #DDE3EC, success green #22B573 for read receipts. Load https://fonts.googleapis.com/css2?family=Nunito:wght@400;600;700&family=JetBrains+Mono:wght@500&display=swap — Nunito everywhere. LAYOUT: (1) slim header with contact avatar, name, and online dot; (2) main thread — 8+ messages mixing in/out bubbles with tails, one image bubble, a day-divider pill, an emoji-reaction row, and delivered/read receipts; (3) typing-dots indicator; (4) composer bar with attachment, input, send; (5) right sidebar with thread list and unread badges. MOTION: new bubbles enter with scale 0.7→1 and translateY 10px→0 over 280ms spring cubic-bezier(0.34,1.56,0.64,1); typing dots bob on a 1.1s loop with 140ms stagger; reactions pop 0→1.3→1 over 320ms with slight rotation; receipts fade+rise 4px 200ms after each bubble settles. SIGNATURE: (a) CSS-tail bubbles in distinct in/out shapes, (b) the living typing indicator, (c) emoji reaction chips. CONSTRAINTS: semantic HTML (main/section, aria-live polite on thread), 4.5:1 contrast, single column below 720px hiding the sidebar, no frameworks, reduced-motion disables bob loops. DELIVERY: Ship one self-contained index.html. Define CSS custom properties --bg:#ECEFF4, --surface:#FFFFFF, --fg:#22252B, --muted:#7C838F, --accent:#0B93F6, --accent2:#E4E9F0, --border:#DDE3EC on :root and use them everywhere — no hard-coded colors. Preconnect to fonts.googleapis.com and fonts.gstatic.com, load Nunito, Nunito, and JetBrains Mono with display=swap and a system-font fallback stack to prevent layout shift. Implement the motions (bubble spring, typing dots, reaction pop, receipt fade) exactly as specified; wrap every ambient loop in @media (prefers-reduced-motion: reduce) to disable. Verify before delivery: all headings in a logical h1→h3 order, focus-visible outlines on interactive elements, no horizontal overflow at 360px viewport, and images with width/height attributes to avoid CLS.
