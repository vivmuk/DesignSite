Description

The Linear school of product design: muted lavender-gray surfaces floating on a near-black background, tight 6px radii, and typography tuned for dense information. Every interaction assumes a keyboard — a command palette is the primary navigation, and shortcuts are printed everywhere. The result is software that feels fast, quiet, and obsessively organized.

Agent build prompt — copy this into any AI agent

ROLE: You are a senior product engineer building a marketing and app surface for a project-management tool in the Linear Precision style — quiet, dense, keyboard-first, obsessively organized. LOOK: near-black #08090D background, panels in #101218, primary text #E2E4ED, secondary #8A8F98, hairlines #23252E, indigo accent #5E6AD2 with lighter #9CA1F0 for hovers. Radii are tight: 6px on cards, 4px on buttons — nothing pill-shaped. Import fonts: https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500&display=swap — Inter at -0.01em letter-spacing for UI, JetBrains Mono for keyboard chips, IDs and code. A faint radial lavender glow (rgba(94,106,210,.18)) sits behind the hero. LAYOUT: slim 56px sticky top bar with product mark, breadcrumb center, avatar cluster right; below it a two-pane layout — 240px icon+label sidebar, main column with a filter row of kbd chips, then a dense issue table (32px rows, hover reveals accent bar); a marketing hero above with headline, one paragraph, dual CTAs and a screenshot frame. MOTION: View Transitions API for route swaps (90ms fade out, 180ms cubic-bezier(.2,.8,.2,1) slide up in); command palette springs from 0.97 scale + 6px offset over 160ms ease-out; row hover tint rgba(255,255,255,.03) at 70ms; stat counters count up 700ms ease-out with tabular-nums. Use no animation library — CSS transitions plus 30 lines of vanilla JS suffice. SIGNATURE: (1) a working ⌘K palette with fuzzy filter and grouped results; (2) kbd chips (1px border, 4px radius, JetBrains Mono 11px) beside every action; (3) left accent bar scaleY animation on active/hover rows; (4) tabular-nums everywhere numbers appear. CONSTRAINTS: semantic HTML5 with proper nav/main/table landmarks; WCAG AA contrast (verify #8A8F98 on #101218); responsive — sidebar collapses to icon rail under 900px, single column under 640px; prefers-reduced-motion disables palette spring and counters; all keyboard navigation works (Tab, arrows in palette); no layout shift from font loading (font-display: swap + metric fallbacks); images lazy-loaded, total JS under 15KB.
