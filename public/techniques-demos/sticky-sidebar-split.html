Introduction

This docs page has three scroll regions in one viewport: the main article, the product nav rail, and the table of contents. Both rails are position:sticky with different containment so they hold while the center column scrolls beneath them.

Sticky positioning works within the nearest scrolling ancestor — because the rails are grid children with align-self:start, each pins independently at top:5.5rem, just below the sticky header.

Installation

Filler installation copy — scroll to watch the rails hold position. Notice the TOC highlights the section currently in view; that is a tiny IntersectionObserver, not scroll math.

More filler paragraphs give the article enough height for both rails to demonstrate their stickiness across the full page.

Configuration

Each rail clamps to max-height:calc(100vh - 7rem) with overflow:auto, so even long nav lists scroll internally without ever pushing the page.

scroll-margin-top on sections keeps anchor jumps from hiding headings under the sticky header — a small but pro-grade detail.

Deployment

Deployment filler. The grid is 200px, 1fr, 180px; both side rails would collapse to static flow on narrow screens in a real build via a single media query.

FAQ

Final section. When you reach the bottom, note that neither rail has moved an inch since you passed its scroll window — that is the pattern working.
