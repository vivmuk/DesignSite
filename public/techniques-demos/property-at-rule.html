Typed Custom Properties: @property

A conic-gradient progress ring that transitions because --angle is registered as <angle>.

This browser doesn't support @property — the ring jumps instead of animating, but still works.
0%

Registered with:

@property --angle {
  syntax: '<angle>';
  inherits: false;
  initial-value: 0deg;
}

Without @property, custom properties are untyped strings and can't be transitioned — here transition: --angle .1s linear makes the gradient sweep smoothly, and even an auto-loop animation works (watch after 3s).
