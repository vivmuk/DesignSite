The reset used on the right pane is the classic modern set: box-sizing, margin zeroing, media max-width, font inheritance for controls, and text-size-adjust.

*, *::before, *::after { box-sizing: border-box; } * { margin: 0; } img, video { max-width: 100%; display: block; } input, button, textarea, select { font: inherit; }
