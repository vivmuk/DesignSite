Drag the viewport-width slider (or resize the real window): heading, body and caption scale continuously.

Continuous Typography

This paragraph scales with the viewport between its floor and ceiling. Below the fluid range the minimum clamps; above it, the maximum holds — so text never becomes unreadably small or comically large.

caption · clamp(.7rem, .3vw + .5rem, .9rem)

Notice there are no media queries anywhere on this page. The type never snaps — between 320px and 1800px it climbs a straight line, clamped at both ends like a hand on a rail.
