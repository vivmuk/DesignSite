The page CSS above deliberately tries to bleed into the widget (red background, tiny uppercase text, square buttons). A declarative shadow root makes that impossible — view source to see the template rendered without any JS.

This markup uses <template shadowrootmode="open"> — declarative Shadow DOM, parsed directly from HTML with zero script. Compare with the page's hostile CSS: the widget keeps its rounded corners, dark card, and own font sizes. Custom properties (--card, --fg, --mut) are the sanctioned styling API across the boundary.
