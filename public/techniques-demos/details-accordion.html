FAQ — zero JavaScript

Exclusive accordion via name="faq" (only one open at a time — browser-managed), animated purely with interpolate-size: allow-keywords.

What makes this accordion special?

No ARIA attributes, no state management, no JS. The name attribute on <details> gives exclusive-open behavior natively — the browser closes siblings when one opens, with correct semantics baked in.

How does the height animation work?

interpolate-size: allow-keywords lets CSS transition to and from height:auto. The .body wrapper starts at height:0 and transitions to auto when the [open] attribute appears — smooth in Chromium 129+.

What about browsers without those features?

Everything still works: details open and close instantly (the base HTML behavior from 2010), and the fallback notice below tells you what's missing. Progressive enhancement all the way down.

Can users deep-link to an open item?

Yes — give each details an id and it will auto-open when navigated to via a fragment URL. That's native behavior too, no scripting required.
