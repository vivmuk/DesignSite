Responsive Flex Toolbar

Drag the slider (or the dashed frame corner). A flexible spacer pushes trailing actions right; wrapping kicks in when space runs out.

container width 560px

The .spacer element with flex: 1 1 auto eats all free space, pushing trailing actions right. When buttons no longer fit, flex-wrap: wrap reflows them. Try setting the width below 340px to see wrapping kick in — a production toolbar would move overflow items into the ⋯ menu with a ResizeObserver.
