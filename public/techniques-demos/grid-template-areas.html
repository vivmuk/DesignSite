Each region is a named grid area. The layout is literally written as ASCII art: rows of quoted names map each cell. Rearranging the page means rewriting the string — no DOM reshuffling, no float hacks.

Watch the footer and header stay full-bleed while nav and aside reposition when you hit the breakpoint button. On mobile the three middle columns stack into one: the same four elements, one changed string.

Areas must form a rectangle — the parser rejects L-shaped region definitions at parse time, which is a surprisingly useful correctness check.
