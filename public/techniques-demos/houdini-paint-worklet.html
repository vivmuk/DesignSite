Houdini Paint Worklet

Custom background painting registered via CSS.paintWorklet.addModule() — confetti and hatching drawn in JS, styled in CSS.

CSS Paint API isn't supported here — cards render with plain backgrounds.

Confetti worklet

Random dots painted per element box. Density and color are input properties, so the slider repaints instantly.

Hatching worklet

Diagonal line texture. Angle follows the second slider — geometry computed inside the paint worklet.

The worklet registers itself with registerPaint(), declares inputProperties, and CSS consumes it with background-image: paint(confetti).
