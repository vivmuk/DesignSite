Two dark-mode approaches, one page

Approach A: media query only (@media (prefers-color-scheme: dark)) — automatic but not user-overridable. Approach B: [data-scheme] attribute + pre-paint script — user control, no flash. This page uses B for real and simulates both below.

❌ Media-query-only

Follows OS, but the user can\'t force light in a dark room or vice versa. And if you also hardcode colors, components mismatch.

✅ data-scheme + pre-paint guard

Inline head script reads localStorage/prefers-color-scheme and sets the attribute BEFORE first paint → zero flash. Toggle actually switches this page.
