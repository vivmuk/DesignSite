The Breakout Grid

Toggle each element between content-width and full-bleed breakout — named grid columns, zero JS positioning.

Modern editorial layouts keep prose in a comfortable measure while letting certain elements escape to the viewport edges. The trick is a three-column grid where the middle track holds the content and side tracks are free real estate.

Fig. 1 — an image spanning columns 1 to -1.

The mechanism is deliberately boring: children default to grid-column: 2; anything marked .full spans 1 / -1. No negative margins, no viewport math, no container queries required.

Good layout systems make the exceptional case one class name away, not one hack away.
grid-template-columns:
  1fr min(66ch, 92%) 1fr;

Because every child participates in the same grid, alignment survives any breakout — full-bleed elements still share edges with the constrained ones.

Toggle each button above and watch the edges: the measure of the prose stays put while the broken element stretches to the same viewport gutter on both sides. This is the entire trick behind modern editorial frameworks — one grid, two column assignments, zero magic.
